# CJK Input Atlas — 综述补充材料

**打开方式：**完整解压后双击 `index.html`，无需安装、登录或启动服务器。`paper-index.html` 是不依赖 JavaScript 的原文目录。

网站采用白底黑字，顶栏下方直接展示逐篇图像目录，优先使用原文图或表，页面预览明确标注。侧栏依照综述的四代算法方法、发表时段与交互方式分类，XR 单列为场景；搜索也位于侧栏。详情页优先呈现原始媒体。手机上可展开“分类筛选”调整条件。

- `papers/` 包含全部 241 篇 PDF：EN-A 57 篇、EN-B 184 篇。
- 三个入口：完整图谱、算法类、交互类。算法 110 篇、交互 181 篇，其中 50 篇交叉；总数仍为 241 个唯一条目。
- 显示语言：English（默认）、中文、日本語、한국어；论文原始标题与文献署名保留。
- 支持标题搜索，叠加发表渠道、研究文字、算法／输入方式及媒体筛选。
- 每篇有包内 PDF 和原始发表出处；链接的可访问、受限、失败状态分别记录。
- 包含逐篇图像索引、2 个 GIF、8 条视频来源。外部视频需要联网；其中两个历史视频链接当前不可用，已明确标注。

汉字转换 GIF 提取自 ACL 2014 官方报告的 02:15、02:35、02:55、03:25 四帧，属于模型说明幻灯片，并非实时输入实验。另一 GIF 为作者仓库的 Flick-in 假名输入动图。各处区分 Hanzi、Kanji、Hanja、假名、Hangul 和物理字形绘制。

`data/catalogue.csv` 提供目录与四语解读；`data/verification.json` 提供逐篇原文／媒体核验；`data/view-classification.csv` 提供阅读视图归类；`data/paper-files.json` 记录每篇 PDF 的来源和打包后校验值；`data/media-credits.md` 记录媒体署名与许可；`SHA256SUMS.txt` 用于文件完整性校验。

241 篇 PDF 均与已有全文阅读记录核对。包内副本清除标准元数据和交互批注，并逐页比较提取文本；其中一份整期刊物仅提取了所纳入文章，对应原 PDF 第 37–50 页。论文印刷内容及原作者署名保留。

论文文件保留各自的著作权，收录于本资料包并不授予新的转载许可。公开网站提供原文入口、带出处的论文配图节选及另有许可的媒体；新增节选不被标作已获开放许可。`source/` 是可维护的 React／TypeScript 源码，详见 `SOURCE-README.md`。

资源与综述的转换和交互主线对齐，不预设新的使用效果；未修改论文正文。出版网站受限时已如实记录，本地全文核验不等于出版页可免费访问。
