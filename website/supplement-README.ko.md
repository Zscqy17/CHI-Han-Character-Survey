# CJK Input Atlas — 문헌고찰 보조 자료

전체 압축을 푼 뒤 `index.html`을 여세요. 설치·로그인·로컬 서버가 필요하지 않습니다. `paper-index.html`은 JavaScript 없이 사용할 수 있는 PDF 목록입니다.

흰 배경과 검은 글자를 사용하며 헤더 바로 아래에 모든 논문의 이미지 목록을 표시합니다. 원문 그림·표를 우선 사용하고 페이지 미리보기는 명시합니다. 사이드바는 문헌고찰의 네 알고리즘 세대, 발표 시기, 입력 방식에 따라 분류하며 XR은 사용 환경으로 구분합니다. 검색도 사이드바에 있습니다. 휴대전화에서는 분류 필터를 펼칠 수 있습니다.

`papers/`에 논문 PDF 241편이 있습니다(EN-A 57편, EN-B 184편). 전체 목록 외에 알고리즘 110편과 상호작용 181편의 독립적인 화면을 제공합니다. 50편은 중복되며 전체 고유 논문은 241편입니다. EN-A/EN-B는 발표 매체 그룹입니다.

English(기본), 中文, 日本語, 한국어를 전환할 수 있습니다. 원래 제목과 저자 표기는 유지합니다. 제목 검색과 매체·문자·방식·미디어 필터를 함께 사용하며, 각 기록에서 포함된 PDF와 원 발표 출처를 열 수 있습니다.

논문별 이미지 색인, GIF 2개, 영상 출처 8개를 포함합니다. 외부 영상은 인터넷 연결이 필요하며 오래된 URL 2개는 이용 불가로 표시했습니다. 한자 변환 GIF는 ACL 2014 공식 발표의 02:15, 02:35, 02:55, 03:25 프레임으로 만든 모델 설명이며 실시간 입력 실험이 아닙니다. 다른 GIF는 저자가 제공한 Flick-in 가나 입력 애니메이션입니다. Hanzi·Kanji·Hanja·가나·한글·물리적 글리프를 구분합니다.

`data/`에는 4개 언어 목록, 출처 검증, 관점별 분류, PDF 대응표, 미디어 저작자·라이선스가 있습니다. `SHA256SUMS.txt`로 파일 무결성을 확인할 수 있습니다. PDF의 표준 메타데이터와 대화형 주석을 제거하고 페이지 추출 텍스트를 원본과 대조했습니다. 합본 한 건에서는 해당 논문(원 PDF 37–50페이지)만 추출했으며 인쇄된 저자명과 본문은 유지했습니다.

각 논문의 권리는 원 권리자에게 있으며 이 자료가 새로운 재배포 권한을 부여하지는 않습니다. 공개 사이트는 원 출처 링크, 출처가 표시된 논문 발췌 이미지, 별도 라이선스가 있는 미디어를 제공합니다. 새 발췌 이미지에 확인되지 않은 공개 라이선스를 부여하지 않습니다. `source/`에 유지보수 가능한 React/TypeScript 소스가 있으며 개발 방법은 `SOURCE-README.md`에 있습니다. 변환과 상호작용이라는 문헌고찰의 흐름을 따르는 보조 자료이며 새로운 효과를 주장하지 않습니다.
