# CJK Input Atlas — レビュー補助資料

アーカイブ全体を展開し、`index.html` を開いてください。インストール、ログイン、ローカルサーバーは不要です。`paper-index.html` はJavaScriptなしでも使えるPDF一覧です。

白地に黒文字の画面で、ヘッダー直下に全論文の画像一覧を表示します。原文の図・表を優先し、ページのプレビューは明記します。サイドバーの分類はレビューの4世代のアルゴリズム、発表時期、入力方式に対応し、XRは利用場面として分けています。検索もサイドバーにあります。スマートフォンでは「絞り込み」を展開できます。

`papers/` に全241件のPDFがあります（EN-A 57件、EN-B 184件）。全体一覧に加え、アルゴリズム110件とインタラクション181件の独立した表示があります。50件が重複し、全体は241件です。EN-A/EN-Bは発表媒体の分類です。

English（既定）、中文、日本語、한국어を切り替えられます。原題と引用著者は保持します。タイトル検索、媒体群、文字、方式、メディアの絞り込みに対応し、各記録から同梱PDFと掲載元を開けます。

論文ごとの画像索引、GIF 2点、動画出典8件を収録しています。外部動画は接続が必要で、古い2件のURLは利用不能と明示しています。漢字変換GIFはACL 2014の公式発表の02:15、02:35、02:55、03:25を抽出したモデル解説であり、実時間入力実験ではありません。もう1点は著者提供のFlick-in仮名入力GIFです。Hanzi、Kanji、Hanja、仮名、Hangul、物理的字形を区別します。

`data/` に四言語の一覧、出典検証、視点別分類、PDF対応表、メディアの署名・ライセンスがあります。`SHA256SUMS.txt` でファイルを検証できます。PDFの標準メタデータと対話的注釈を除去し、ページの抽出テキストを原本と照合しました。合冊1点からは対象論文（元PDF 37–50ページ）のみを収録し、印刷された著者名と本文を保っています。

各論文の権利は原著者・権利者に帰属し、この資料は新しい転載権を付与しません。公開サイトは掲載元リンク、出典付きの論文抜粋画像、別途ライセンスのあるメディアを提供します。新たな抜粋に未確認のオープンライセンスを付与しません。`source/` に保守可能なReact/TypeScriptソース、`SOURCE-README.md` に開発手順があります。レビューの変換・操作という軸に沿う補助資料であり、新たな有効性は主張しません。
